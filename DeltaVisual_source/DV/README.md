# Delta Visual (Forge 1.16.5)

Клиентский визуал-мод с собственным меню (открывается на Right Shift).
Модули: Fullbright, Zoom, Watermark, FPS, Coordinates.

## Сборка jar через GitHub
1. Создай репозиторий и залей всё содержимое этой папки (включая скрытую `.github`).
2. Вкладка Actions -> Build Delta Visual -> Run workflow (или просто сделай push).
3. Готовый jar лежит в Artifacts: DeltaVisual-jar.
4. Кинь jar в папку mods (Minecraft 1.16.5 + Forge 36.2.39+).

Свой логотип: замени `src/main/resources/logo.png`.
